Drop OP-1 drum-pack .aif (or .aiff) files here (from op1.fun or the OP-1
pack builder) to import them as Kits -- one file per kit, each slice on
its own pad. Plain recordings with no OP-1 data import as a single pad.

SMPDR -> Import page -> Kits. Each kit lands in its own folder under
SAMPLES/KITSn/, named after the file -- op1.fun often names downloads
"patch.aif", so rename the file first to give the kit a proper name.
Imported files move into Done/. A file that fails is tried twice, then
left here for the next Import.
