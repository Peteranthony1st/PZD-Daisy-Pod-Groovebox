Drop break/loop .aif (or .aiff) files here -- OP-1 drum packs or plain
recordings -- to import them as Breaks, however they're sliced.

SMPDR -> Import page -> Breaks. Each break lands in its own folder under
SAMPLES/BREAKSn/, named after the file -- op1.fun often names downloads
"patch.aif", so rename the file first to give the break a proper name.
Breaks start with Choke on, since their slices are pieces of one
recording. Imported files move into Done/. A file that fails is tried
twice, then left here for the next Import.
