Drop raw OP-1 drum-pack .aif files here (downloaded from op1fun, or
exported from the OP-1 pack builder) -- one .aif per drum kit.

Screen::SampleSynth -> Import page: Button1 picks Kits/Sounds/All,
Button2 held converts every .aif in here into a real, playable Kit
(Screen::SampleSynth -> Preset page). Each slice lands on its own key,
using the splice points already baked into the file.

Successfully-imported files move into their own Done/ subfolder
automatically, so running Import again never reprocesses them.
