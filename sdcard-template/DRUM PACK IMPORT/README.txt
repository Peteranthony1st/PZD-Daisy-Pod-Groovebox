Drum packs go in one of the two folders in here -- the folder you drop a
file into decides what it becomes; nothing is sorted automatically:

  KITS/    one-shot drum kits (a different sound on each pad)
  BREAKS/  breaks and loops (one recording chopped into slices)

Files left loose in this folder are not imported -- move them into
KITS/ or BREAKS/ first.

SMPDR -> Import page: K1 picks Kits or Breaks, B2 opens it. Then K1 picks
where they go (a new bank, or an existing one with room for all of
them) and holding B2 imports every file in that folder.
