SampleSynth Drum (SMPDR) Breaks -- same layout as KITS1/ (one folder
per break, KIT.DAT plus its own 01.wav, 02.wav, ...), kept separate so
loops don't get mixed in with drum kits.

A drum pack is filed here instead of KITSn/ when its typical slice is a
second or longer (whole bars or phrases rather than single hits), or
when it was imported from BREAK PACK IMPORT/. Up to 32 per BREAKSn
folder; BREAKS2/, BREAKS3/, ... are created automatically.

Load one from Screen::SampleSynth (Drum) -> Preset page, then split it
across the keys with the Setup page's Break Divide.
