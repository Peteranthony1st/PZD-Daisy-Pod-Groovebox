SampleSynth Drum (SMPDR) Breaks -- same layout as KITS1/ (one folder per
break), kept separate so loops don't get mixed in with drum kits.

Two ways to make one:
- Import a pack from DRUM PACK IMPORT/BREAKS/.
- Make a folder here yourself and copy WAVs into it -- a single loop is
  fine (one pad); the Setup page's Break Divide chops it into equal slices
  across the keys.

Breaks start with Choke on, since their slices are pieces of one
recording. Up to 32 per BREAKSn folder; BREAKS2/, BREAKS3/, ... are
created automatically.

Load one from Screen::SampleSynth (Drum) -> Preset page.
