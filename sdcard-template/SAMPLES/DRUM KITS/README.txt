SampleSynth's drum Kits live here (KIT001.DAT, KIT002.DAT, ...) --
each one is a small manifest (which WAV file maps to which pad/key)
plus the engine's own Filter/Env/Mix/FX settings, saved/loaded from
Screen::SampleSynth (Drum mode) -> Preset page.

Created automatically the first time you save or import a Kit -- this
folder is only pre-made here so a fresh card already matches a
populated one.
