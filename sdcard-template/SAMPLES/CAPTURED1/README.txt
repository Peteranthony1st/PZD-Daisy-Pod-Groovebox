SampleSynth's own Capture/Trim saves land here -- Screen::SampleSynth
-> Trim page, hold Button2 to save whatever's currently trimmed as a
real Sound file (CAP001.wav, CAP002.wav, ...).

Up to 32 per folder: once this one is full, saves go into CAPTURED2/,
then CAPTURED3/, and so on -- created automatically.

This README.txt is harmless to leave here -- the firmware only ever
looks for real .wav files in this folder.
