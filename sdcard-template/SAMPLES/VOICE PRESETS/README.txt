SampleSynth's own SMPVO (Voice) User presets live here (PRES001.DAT,
PRES002.DAT, ...) -- each one is a reference to a Sound (not a copy of
its audio) plus a full settings snapshot (Filter/Env/Mix/FX, Tune,
Mono/Poly), saved/loaded from Screen::SampleSynth (Voice mode) -> User
page.

Created automatically the first time you save one -- this folder is
only pre-made here so a fresh card already matches a populated one.
