SampleSynth Voice (SMPVO) Sounds -- plain .wav files (and .snd
multi-sample manifests) live here, up to 32 per folder.

Imported OP-1 sampler packs (SOUND PACK IMPORT/) land here too. Once
this folder holds 32, new ones go into SOUNDS2/, then SOUNDS3/, and so
on -- created automatically, nothing to set up. You can also drop .wav
files straight into any SOUNDSn folder yourself.

Browse them from Screen::SampleSynth (Voice) -> Preset page: pick a
folder ("Sounds 1"), then a file. Sub-folders inside a SOUNDSn folder
are ignored.
