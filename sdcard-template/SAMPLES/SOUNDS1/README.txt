SampleSynth Voice (SMPVO) Sounds -- single .wav files, up to 32 per
folder. Each plays across the whole keyboard.

Imported OP-1 sampler packs (SOUND PACK IMPORT/) land here. You can also
copy .wav files straight into any SOUNDSn folder yourself -- any sample
rate, 16/24/32-bit or float, mono or stereo, up to about 33 s. A note at
the end of the name ("Cello C3.wav", "Cello_C3.wav") sets its root pitch;
otherwise it plays with C4 as the root.

Several recordings of one instrument at different pitches belong in a
MULTISMPn folder instead (see MULTISMP1/README.txt).

Browse from Screen::SampleSynth (Voice) -> Preset page -> Sounds, then a
folder ("Sounds 1"), then a file. Sub-folders inside a SOUNDSn folder
are ignored.
