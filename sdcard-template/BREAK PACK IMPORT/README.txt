Drop break/loop .aif (or .aiff) files here -- OP-1 drum packs or plain
recordings -- to import them as Breaks no matter how they're sliced.

DRUM PACK IMPORT/ already sorts packs automatically (a typical slice of
a second or longer = Break, shorter = Kit); this folder is for the ones
that would otherwise be guessed wrong, such as a break already chopped
into single hits.

Screen::SampleSynth -> Import page: Button1 picks Drums/Sounds/All,
Button2 held imports every file in DRUM PACK IMPORT/ and here.
Successfully-imported files move into their own Done/ subfolder. A file
that fails is tried twice, then left here for the next Import.
