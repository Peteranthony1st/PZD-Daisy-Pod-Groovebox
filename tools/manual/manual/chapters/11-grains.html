Grains

Grains is a granular instrument. It plays a sound as a cloud of short grains, so it can stretch, freeze, scatter and re-pitch it. The sound can be captured live, taken from an audio track, imported as a WAV, or loaded with a preset. Open it from Global:Grains.

How it plays

  • Position is where each note's play pointer sits, and Scan moves it through the sound: ×1.00 replays it at its own speed, slower stretches it without changing pitch, negative runs backwards, and Hold keeps it still. Every note starts at Position, and turning Position while notes play carries the whole cloud with it.
  • The pointer stays between Loop Start and Loop End, and Mode sets what it does at the edges.
  • Spray scatters each grain's start around the pointer. Direction is which way each grain plays its own slice, separate from which way Scan moves the pointer.
  • Grain Size and Density set how long each grain is and how many start each second. A note can have up to 32 grains sounding (fewer each in a chord), so very long grains at a high density thin out and get quieter: keep Size in seconds × Density under about 32.
  • Up to four notes at once, or Mono. With Keymap on, each grain plays at the note's pitch; off, every note plays at the Pitch setting. A fifth note takes over the oldest, its grains fading out.

The waveform shows Position's span and a tick for each sounding note's pointer.

Rhythm

Plays the grains in a 16-step pattern instead of a steady stream; B1 picks the pattern and B2 its speed, with Sync following the tempo. The page draws the pattern.

Capturing a sound

On the Capture page, B1 picks where the sound comes from: Direct records the input, Layer takes an audio track, and Import loads a WAV from GRAINS IMPORT/ on the card. Hold B2 to record or capture. Then on Trim, set the start and end with the knobs, play the result with B1, and hold B2 to save it: it goes into Preset → Captured. LED 2 is red while a capture records.

Grains presets keep their sound with them, so a User save brings back the audio as well as the settings. The card template comes with starter sounds in GRAINS/PRESETS/, Airy Piano first.
